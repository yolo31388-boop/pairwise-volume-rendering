# 游戏内体积渲染与体积雾系统

## 项目描述

游戏内体积渲染与体积雾系统的bug修复项目。核心模块 `rendering/volume.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 体积渲染完全没做雾没有体积感
- 体积雾完全没做只能做简单的高度雾
- 体积光完全没做不能计算光束效果
- 体积云完全没做云都是贴图
- 体积阴影完全没做体积不能投射阴影

## 运行测试

```bash
python -m pytest tests/test_volume_rendering.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
